# Itaú - Java com Inteligência Artificial

Repositório com anotações, exercícios e projetos desenvolvidos durante o bootcamp **Itaú - Java com Inteligência Artificial**, oferecido pela [DIO](https://www.dio.me) em parceria com o Itaú.

## 🎯 Sobre o bootcamp

Trilha gratuita de 45h de conteúdo cobrindo desde os fundamentos de Java até a integração com Inteligência Artificial, incluindo:

- Fundamentos de Java e Programação Orientada a Objetos
- Ecossistema Spring (Spring Boot, Spring Data, Spring Security, Spring Cloud)
- Fundamentos de IA Moderna (Machine Learning, LLMs, IA Generativa e Agentes)
- Desenvolvimento de uma API com reconhecimento de fala
- Design Patterns (GoF) aplicados com Spring Framework

## 🛠️ Tecnologias

- Java
- Spring Boot / Spring Data / Spring Security
- Maven/Gradle
- APIs de IA Generativa
