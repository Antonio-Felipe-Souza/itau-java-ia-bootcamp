# Itaú - Java com Inteligência Artificial

Repositório dedicado aos estudos e projetos desenvolvidos durante o bootcamp **Itaú - Java com Inteligência Artificial**, realizado pela [DIO](https://www.dio.me) em parceria com o Itaú.

O intuito deste repositório é registrar minha evolução no desenvolvimento **Backend com Java**, reunindo exercícios, anotações e projetos práticos desenvolvidos ao longo da trilha.

## 📌 Objetivo

Utilizar o bootcamp como parte da minha evolução em **Backend Java**, consolidando fundamentos da linguagem e avançando posteriormente para desenvolvimento de APIs e aplicações utilizando o ecossistema Spring.

Este repositório também serve como registro prático da minha evolução, reunindo os exercícios e projetos desenvolvidos ao longo da formação.

## 🎯 Sobre o bootcamp

Bootcamp com **45 horas de conteúdo**, abordando desde os fundamentos da linguagem Java até desenvolvimento de aplicações com Spring Boot e integração com Inteligência Artificial.

Durante a formação, são trabalhados conceitos como:

* Fundamentos da linguagem Java
* Programação Orientada a Objetos
* Classes, encapsulamento, herança e polimorfismo
* Interfaces, Lambda e Collections
* Tratamento de exceções e I/O
* Dependências e gerenciamento de projetos
* Persistência de dados
* Spring Boot e ecossistema Spring
* Design Patterns
* Inteligência Artificial Generativa e LLMs
* Integração de IA em aplicações Java
* Desenvolvimento de API com reconhecimento de fala

Além dos conteúdos teóricos, a formação conta com **desafios de código e projetos práticos**, permitindo aplicar os conceitos estudados em situações próximas às encontradas no desenvolvimento de software.
